# Name

HDL_Source_Revision_Controlled_Git

# Title

HDL Source Revision-Controlled Git Repository

# Overview

This repository is intended for the management and maintenance of HDL (Hardware Description Language) source code. It provides a structured environment for development, review, and versioning of HDL files, using Git as the revision control system.

# Objectives

* To store and organise HDL source code in a structured repository.
* To use revision control for tracking changes, maintaining history, and supporting collaborative development.
* To provide transparency in development and enable reliable rollback to stable versions.
* To facilitate code review and comparison of revisions.

# Scope of Use

* Digital design projects, including FPGA and ASIC development.
* Engineering teams requiring collaborative version control.
* Educational environments where HDL development is combined with version control practices.

# Tools

* Git as the primary revision control system.
* Simulation and synthesis tools commonly used in hardware design.
* CI/CD tools may be integrated for automated testing and verification.

# Naming Convention

A consistent naming convention shall be used for all project-defined names throughout the repository.

* Use lowercase letters only.
* Use underscores to separate words.
* Numbers are allowed.
* Do not start or end a name with an underscore.
* Do not use consecutive underscores (`__`).

This convention applies to source files, directories, HDL objects, scripts, constraints, and other project-defined names across the repository.

Vendor-defined names, language keywords, tool commands, tool properties, and standard interface names are excluded from this convention.
