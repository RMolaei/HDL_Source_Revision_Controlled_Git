Title
HDL Source Revision-Controlled Git Repository

Overview
This repository is intended for the management and maintenance of HDL (Hardware Description Language) source code. It provides a structured environment for development, review, and versioning of HDL files, utilising Git as the revision control system.

Objectives
  * To store and organise HDL source code in a central repository.
  * To employ revision control for tracking changes, maintaining history, and supporting collaborative work.
  * To ensure transparency in development and enable reliable roll-back to stable versions.
  * To facilitate code review and comparison of revisions.

Scope of Use
  * Digital design projects, including FPGA and ASIC development.
  * Engineering teams requiring collaborative version control.
  * Educational settings where HDL is taught alongside version control practices.

Tools
  * Git as the primary revision control system.
  * Potential integration with CI/CD pipelines for automated testing of HDL code.
  * Compatibility with simulation and synthesis tools commonly used in hardware design.
